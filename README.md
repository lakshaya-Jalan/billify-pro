# Billify Pro — Premium Multi-Business Billing App

Modern, animated, multi-tenant billing software.

## Features
- Multi-business support (each user has isolated data)
- Beautiful modern UI with glassmorphism + animations
- Products management (with per-product tax)
- Customers management
- Create bills with multiple items
- PDF generation with company watermark
- Payment status (Pending / Half Paid / Fully Paid)
- Dashboard with stats
- Fully responsive

## How to use
1. Open `index.html` in browser (or host on GitHub Pages)
2. Sign Up → Create your business
3. Add products → Create bills → Generate PDF

## Tech
- Supabase (Auth + Database)
- Tailwind CSS
- GSAP Animations
- jsPDF
